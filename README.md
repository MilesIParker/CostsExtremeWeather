# CostsExtremeWeather

Replication material for the extreme-weather cost estimates of Sehrish Usman,
Guzmán González-Torres Fernández, Maximilian Kotz, Friderike Kuik, Eliza Lis,
Christiane Nickel, Miles Parker and Mathilde Vallat.

## Contents

- **`output/`** — summer 2026 output-loss (GVA) estimates: the code and data
  behind the current paper. Start with [`output/README.md`](output/README.md).
- **`inflation/`** — summer 2026 price and inflation estimates.
- **`output_2025/`** — summer 2025 estimates, the previous round, kept for
  reference. See [`output_2025/README.md`](output_2025/README.md).

The impact coefficients applied in all of these are estimated in a companion
paper, not here:

Sehrish Usman, Guzmán González-Torres Fernández, Miles Parker, "Going NUTS: The
regional impact of extreme climate events over the medium term", *European
Economic Review*, 2025, 105081,
https://doi.org/10.1016/j.euroecorev.2025.105081 — replication package at
https://github.com/MilesIParker/GoingNUTS

Kotz, M., F. Kuik, E. Lis, and C. Nickel (2024). Global warming and484
heat extremes to enhance inflationary pressures. Communications Earth and485
Environment 5 (116).
https://www.nature.com/articles/s43247-023-01173-x
Replication package (Zenodo): https://doi.org/10.5281/zenodo.10183679
